# 投入产出网络中关键行业识别与产业链韧性提升

## 基于结构诊断和冲击模拟

这是一篇将前两条研究路线整合后的论文初稿配套案例，而不是把两篇论文的结果简单拼接。其中心问题是：**结构上处于中心的行业，是否一定具有更大的系统冲击影响？当恢复资源相同时，应该优先恢复哪些联系？**

从网络结构视角论文保留中心性、熵权 TOPSIS 与结构诊断；从传播动力学论文保留投入产出权重、网络效率和明确校准的 SIR 辅助分析。共同主线改为：

**同一输入数据 → 结构候选排名 → 同比例/同金额冲击验证 → 滞后信息选取恢复目标 → 同预算恢复比较 → 阈值与动态权衡检验。**

结构指标是待检验的预测量，不预先认定为韧性本身。主结果变量是固定节点集合上的加权网络效率损失；SIR 的峰值、累计受影响比例和恢复时间用于展示参数映射下的权衡，不承担因果识别。

## 本次增加的研究内容

- 2009–2023 年、42 行业，共 1,260 个主冲击情景。
- 同比例冲击与同金额冲击分开，暴露结构排名对冲击口径的依赖。
- 与度、强度、产出规模等简单指标比较，不预设 TOPSIS 优于简单基线。
- 2020/2023 年使用上一年信息选目标，2,016 个预算受约束恢复情景。
- 恢复金额不超过损失、任一边不超过冲击前水平，并加入 100 组固定随机目标作为对照。
- 正面报告“结构排名不稳健”“效率改善不保证传播风险下降”等反向证据。

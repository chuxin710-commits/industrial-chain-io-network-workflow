## 本轮规划

1. 阅读首页：紧凑刊头、三主题最新速览、新闻时间线、来源覆盖与采集状态。使用既有视觉语言；按新旧排序，不构造热度分数。
2. 查找：主题、最近 24/48/72 小时、来源、关键词、阅读状态、历史期刊；筛选后计数、空结果重置、紧凑模式、分批加载。
3. 阅读整理：信息卡片、原文跳转、收藏、手动已读、个人笔记、Markdown 导出。收藏快照可在三天窗口过后继续查看；个人状态只存当前浏览器，不伪称团队同步。
4. 可追溯：原文标题、发布方、发布时间、检索版本、采集时间；历史期刊按当期采集时点保留 72 小时窗口，与当前新闻明确区分。

## 实施边界

不抓取付费正文、不生成推测摘要、不把同主题消息视为同一事件；不增加未经核实的地理标签。RSS 检索版本不是新闻事件发生地。保留每日北京时间 07:00 的服务器定时采集，浏览器刷新只重读已采集结果。

真实标题抽查补充了窄范围噪声过滤：证券市场代码结尾的 Estimates / stock quote 等行情页，以及明确的非法毒品交易标题。普通供应链损失估计、医药生产与药品供应新闻不因这些词被泛化排除。新规则用于当前消息及后续采集，历史快照保留当期内容。关键词筛选仍非编辑审核或事实核验。

历史接口只允许已存在、合法日期命名的快照；当前接口继续以服务器当前时间过滤过期数据。源站故障时保留已有界面并显示失败，不把上期内容标为刚刚采集。

完成构建和本地验收后发布增量包，复用数据/媒体，检查线上 API、定时器和真实页面，再推送新版代码。

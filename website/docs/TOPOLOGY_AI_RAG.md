# 网络解读与共用文献 RAG

## 交互与解释链路

网络生成完成后，工具栏提供「AI 解读」。支持当前年度、全部已生成年份，以及聚焦选中的节点。点击画布或节点表选中节点后，可询问其入强度、出强度和邻居结构。分析结果分为实算观察、机制与假设、下一步检验、解释边界。

1. 浏览器只提交年份、构网参数、可选节点 ID 和问题。服务器不信任浏览器传回的指标、排名或事实。
2. 服务器使用 `TopologyEngine.query()` 重用或重新计算全部阈值网络的结果；多年度采用同一参数。聚合先求和 Z 和 x，再计算 A。
3. 每年度实算事实 F1、F2 等包含全网指标、展示覆盖率、全节点总强度前八、数据和代码哈希。选中节点附带其全网强度、度数、排名和最强十条阈值连接。十条只是精简上下文，不是全部邻居。
4. 按当前问题与研究主题检索私有向量库，将原文及项目知识卡注入 DeepSeek 请求。生成前没有相关证据时明确标注，不伪装成已阅读全文。
5. 实算观察由服务器确定性生成，不让模型重写数字和排名稳定性；校验模型引用 ID，只允许服务器已提供的来源形成链接。原文入口使用物理 PDF 页码。用户可展开检索片段，区分「回答引用」与「检索候选」。
6. 年份、节点、分析范围、生成批次或登录状态变化时清理旧回答，防止误配。取消界面等待不保证取消已计费的远程请求。

## 索引实现与取舍

服务器约 2 GB 内存，首版采用低资源、可复现的经典向量检索，而不是部署神经网络 embedding 模型：

- 中文二、三字片段与英文词组成 TF-IDF 稀疏向量，最多 40,000 维；在当前私有语料上以固定随机种子 710 训练 128 维 TruncatedSVD/LSA（小语料自动降维）。
- L2 归一化后以 `0.65 * TF-IDF余弦 + 0.35 * max(LSA余弦,0)` 排序，增加显式中英文领域词扩展。算法参考 [scikit-learn TF-IDF](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html) 与 [TruncatedSVD](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.TruncatedSVD.html)。
- 这是真实落盘的稀疏和稠密向量索引，不是把全文字符串搜索叫作向量检索；但也不是预训练多语言语义模型，跨语言和复杂同义改写召回能力有限。
- 仅索引当前文献目录内 PDF 哈希匹配、解析版本匹配、状态 ready 的材料。移除/替换文献或重新解析会改变索引指纹；旧版本不能命中当前回答缓存。
- 从已解析 PDF 页文本按 900 字符窗口、120 字符重叠切片，不跨页拼接。短于 50 字符的页/尾片段不索引；不能将索引页数当全部页面均有有效文字。
- 标题、已有标签和概述用于检索特征；注入回答的论文证据仍然是原始页面文本，不把 AI 概述伪装成逐字原文。提取文本可能含 OCR 错误。
- 同时索引八张领域知识卡，明确标记为项目教学/解释补充，不冒充论文结论。引用跳转对应方法手册。
- 每次最多返回两张知识卡、五个论文片段，每篇最多两个不同页面；设置词面和融合分数门槛，避免不相关问题强行填满引用。
- `lexical.npz`、`vectors.npz`、`index.json` 位于私有文献目录 `rag/<内容指纹>/`，不进公共目录、不进 Git，不使用不安全 pickle 反序列化。
- 指纹绑定算法版本、知识卡、词扩展、文献 ID/哈希/解析版本/更新时间和标题。不可变目录原子发布；每次新回答校验当前清单，必要时重建。语料扩张时会重新拟合词表与 LSA，不宣称增量训练。
- 预热后两个 agent 共用内存中的索引，无逐问 embedding 网络调用费用。24 小时内复用相同输入及版本的回答；每次请求仍核验当前知识库版本。索引更新后不会继续命中旧回答。
- API 内存上限由 512 MiB 调整为 768 MiB，为知识库更新时重建索引留出空间，仍受 systemd 限制；向量计算使用单线程 BLAS。

## 方法助教复用

方法助教 v1.4 使用同一 `ResearchRAG`，检索方法标题、当前问题与最近用户问题。当前手册始终优先于论文符号定义。历史上下文不携带旧检索来源，字段或引用校验失败最多额外重答一次。省去第二份向量库存储、训练和常驻内存；收益是复用和可追溯性，不承诺与未检索版本相比生成更快或数学正确率已显著提高。

## API、隐私与成本

- `POST /api/library/ai/topology`，请求 `{years:[2023],config:{level:'sector',weight:'A',threshold:0.005,max_edges:250,display:'local'},node:null,question:'...'}`。
- `GET /api/library/ai/topology/<job_id>`：账号隔离异步任务。沿用文献库会话、同源与 CSRF 校验；匿名访客不能读取私有证据。
- `server/topology_ai.py` 复用方法助教任务队列，各模块最多两个并发、每账号一个运行任务、每小时三十次新提问。不是两个模块合并后的全局限额。
- 服务器缓存分别使用 `topology_ai.sqlite3`、`method_tutor.sqlite3`；启动清理超过七天的任务，服务重启将中断任务标为失败。结果含私有片段，禁止公开缓存。
- DeepSeek 仍接收相关原文片段、问题及精简的数值事实。不是完全离线推理，也不表示文献不离开服务器；不把整库发送给模型。密钥仅存在服务器环境变量。
- 原文片段、用户问题都视为不可信资料；提示词不接受其中的任务改写；前端转义文本，仅放行内部文献/手册链接。

## 科学边界

原有拓扑计算内核未修改。密度、孤立点、强度和度来自全部阈值边，不是画布的 top-K。A 不是概率，强度不是介数、因果重要性或韧性分数。不补写未计算的社区、PageRank、级联损失或恢复曲线。S01-S42 不猜行业名；保留金额单位、价格口径和 2005-2007 来源可比性警告。

引用 ID 校验确认的是来源可追溯，不是逐句蕴含关系验证。AI 仍可能误读段落或数字，需要人工核验。模型没有被允许任意执行代码、上网或修改数据。未来若要升级多语言神经语义检索，应先建立人工标注文献相关性样本，比较 recall@k、引用支持率、延迟和内存，再决定是否替换 LSA。

# Network Display and Highlight Stability

Date: 2026-10-22 (Asia/Shanghai).

## Scope

This delivery implements the first network upgrade increment: local backbone selection, visible coverage diagnostics, bounded annual matrix reuse, and cancellable worker layout. It does not introduce new economic shock assumptions, change A/Z definitions or claim calibrated resilience scores. The original strongest-edge view remains available for comparison.

## Display Contract

API parameter `display` accepts `topk` (backward-compatible API default) or `local` (website default). The strict edge budget and absolute scientific threshold remain independent. Local selection nominates each node's strongest incoming and outgoing edge, then prioritizes unseen endpoints, missing input/output directions, local weight shares, raw weight and deterministic matrix order. Remaining slots take global strongest edges. All original nodes remain.

Full threshold-network metrics and neighbor queries are unchanged. The response now separately reports nonisolated nodes, visibly connected nodes, hidden connected nodes and node coverage. Exports include the display rule and coverage; JSON also records worker execution and layout version. A-weight coverage is not a GDP or transaction-amount share.

## Highlight Repair

Two unstable transitions were removed:

1. A successful save previously discarded its pending mark and requested another annotation fetch. If an older poll was in progress, that fetch returned early and the saved mark could disappear until a later poll.
2. Every overlay refresh replaced all SVG children, even when the geometry was unchanged.

The reader now inserts the acknowledged server annotation immediately, rejects pre-write snapshots, and keeps a stable keyed SVG group from pending through saved state. Failed saves keep their visible pending mark and offer retry. Unchanged synchronization does not replace highlight shapes. The highlighter now uses actual text selection; rectangle marking remains a separate tool. Text selections are retained when offscreen page canvases are released.

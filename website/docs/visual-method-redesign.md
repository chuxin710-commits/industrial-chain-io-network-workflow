## 分支链网

核心不再是“断一环再装一环”，而是“局部失效、分支扩散、替代承压、分阶段重建”。

| 概念阶段 | 时间轴      | 可观察行为                                             |
| -------- | ----------- | ------------------------------------------------------ |
| 稳态     | 0–2 秒      | 主路径保持连接与定向传递，备用支路待命                 |
| 局部破裂 | 2–3.8 秒    | 压力信号到达局部链环，变形、破碎、碎片旋转与两端回弹   |
| 连锁扩散 | 3.8–6.8 秒  | 两个下游分支先后受损，较远支路再断裂，不同步全网变红   |
| 绕行承压 | 6.8–9.6 秒  | 备用路径高亮并传递；主路径仍有缺口，但下游重新可达     |
| 逐段重建 | 9.6–15.6 秒 | 四处连接在不同时间窗口修复，分段链环沿缓动轨迹逐步合拢 |
| 恢复     | 15.6–20 秒  | 主路径恢复，备用路径逐渐回到待命，平滑进入下一轮       |

场景为 8 点、9 分支的有向示意图。4 处破裂分别发生于第 3、4.25、4.95、6.1 秒，满足上游先受损、下游随后受损。绕行经 `0→7→3→5→6`，在修复前已经重新连接起点与下游。这些时间是视觉编排参数，不是估计值。

每处破裂由 6 段弧状碎片与 8 个不规则碎屑构成；碎片向外旋转、下坠、退场，不沿原轨迹倒放。重建采用四段链环错峰接近，缓入缓出、衰减摆动、颜色渐变和链端回位共同完成衔接。这里只用确定性动画，不宣称真实物理计算。

六段阶段控件支持检查过程：选段后暂停，播放从该处继续。颜色区分主链、受损连接、替代承压，不使用未经核验的行业名称或实证数值。

## 验证边界

- 单元测试检查有向分支、级联顺序、先绕行后维修的可达性、重建平滑度及循环状态一致性。
- 浏览器测试检查 Canvas 非空、时间运动、真实鼠标响应、六段状态、阶段选择、暂停与离屏停绘。
- 布局覆盖批注视口 1625×884、桌面 1440×960、手机 390×844 与小屏 320×568，另对生产构建复查。
- 减少动态效果默认静止；无 WebGL 时使用同源静态图并隐藏不可用控件。
- 像素测试证明场景确实绘制和变化，不证明经济模型有效。图形不得冒充论文结果，也不接触私有投入产出表。

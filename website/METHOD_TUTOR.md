# 方法体系 AI 助教

## 范围

每个方法与公式提供 AI 解释入口，包含通俗理解、逐步拆解、合成教学例子、误区及自检题，并支持追问。手册正文和公式不受 AI 可用性影响。沿用课题组文献库登录和服务端 DeepSeek 配置，不增加浏览器密钥或第三方 iframe。

## 数据链路

- `src/method-catalog.js` 是手册定义的单一来源。构建脚本生成 `server/method_catalog.json`，包含方法、公式、符号、参数、边界与来源哈希；打包仅额外允许这个明确命名的 JSON 文件。
- 浏览器只提交方法 ID、公式索引、问题及最近两轮上下文。服务端重新读取可信目录，不接受客户端替换公式或手册。
- `POST /api/library/ai/explain` 创建异步任务；`GET /api/library/ai/explain/<id>` 查询。沿用会话、来源及 CSRF 校验，结果按账号隔离。
- `server/method_tutor.py` 限制全局两个并发、每账号一个并发、每账号每小时 30 次新问题。相同账号、问题、上下文、手册版本、知识库版本、模型及提示词版本在 24 小时内复用结果。
- v1.4 接入与拓扑助理共用的私有 RAG：每次新的模型回答先检索原文与项目知识卡；提问时重新核验索引版本，版本变化不复用旧回答。追问只保留上一轮教学文本，不携带旧检索来源。字段或引用校验失败最多重答一次，仍失败则明确报错，不展示未经校验的回答。检索不覆盖手册定义，证据不足时明确说明。实现及评估见 `docs/TOPOLOGY_AI_RAG.md`。
- 仅服务端调用 DeepSeek，输出采用严格 JSON 结构校验；前端转义所有回答，不执行返回的 HTML。原始公式仍用手册的 KaTeX 渲染，AI 回答中的公式使用纯文本。
- 请求与响应不持久化到浏览器。服务端缓存数据库为文献库根目录下 `method_tutor.sqlite3`，存储结果、请求摘要及账号标识，不存问题或对话原文。服务启动时清理超过七天的缓存并使中断任务失败。AI 结果自身可能复述用户问题，仍按私有数据保护。
- 清空、关闭、切换方法或登录状态变化会丢弃当前界面上下文，并防止旧响应串入新方法。关闭窗口不保证取消已经提交给模型的计费请求。

## 科学边界

AI 以当前手册为定义依据，并检索私有文献库中的相关 PDF 页面片段，不搜索外网。系统提示约束矩阵方向、分母、符号及条件模拟边界；要求自造数字标为合成教学示例，不声称真实计算或因果识别。JSON、引用 ID 校验及版本绑定均不能证明回答数学正确或文献支持了每个推论；重要推导和计算仍需人工复核。没有修改原有科研计算内核。

真实回答抽查发现模型会把“构网阈值”和“展示边数限制”混同，故 v1.1 增加明确约束和相关“阈值与固定支持集”章节上下文：阈值改变参与计算的网络，展示稀疏化才不改变全部阈值边上的指标。提示词版本参与缓存键，不继续复用旧回答。

v1.2 进一步明确“可能影响”而非“必然改变”：未跨越边权时支持集可不变，即使支持集变化也非每项指标必然变化。

## 验证

```text
npm run build
python -m unittest discover -s scripts -p test_method_tutor.py -v
python -m unittest discover -s scripts -p test_library.py -v
node --test scripts/methods.test.mjs
node scripts/verify-method-tutor.mjs
node scripts/verify-methods.mjs
python scripts/verify-method-tutor.py
```

最后一项对线上模型实际提问，通过隐藏输入接收密码，不写入文件。合成浏览器测试覆盖登录门槛、公式上下文、追问、错误重试、关闭后重新打开、过期响应、退出清理、文本转义，以及 1440 / 390 / 320 像素布局。
